# Claudeに貼るだけセットアップ

## 使い方

1. Claude Desktopを開く
2. 下のプロンプトをまるごとコピーしてClaudeに送る
3. あとはClaudeの指示に従うだけ！

---

## ここから下をコピー ↓↓↓

```
以下のGitHubリポジトリは、Illustratorの入稿チェックを自動化するツールです。
これを私の環境にセットアップしてください。

https://github.com/nagi-inaba/mcp-illustrator

私はデザイナーで、エンジニアではありません。
ターミナルやコマンドの操作はほぼ初心者です。

以下の手順を、ひとつずつ私に指示してください：

1. 必要なソフト（Node.js、Git）がインストールされているか確認
   → 入ってなければインストール手順を教えて
2. adb-mcp（Claude↔Illustrator連携ツール）のインストール
3. Illustrator側のCEPパネルの設定
4. Claude Desktopの設定ファイル（claude_desktop_config.json）の編集
5. リポジトリのskillsフォルダの中身を、このプロジェクトのProject Knowledgeに登録する方法
6. 動作確認（Illustratorを開いて「ドキュメント情報を教えて」と話しかけるところまで）

注意点：
- 私のOSは [Mac / Windows]（←自分のを残してね）
- 一度に全部説明しないで、1ステップずつ進めてほしい
- 各ステップが終わったら「できた」と言うので、次に進んで
- エラーが出たらスクショを貼るので、一緒に解決してほしい
- 専門用語はなるべく使わないで
```
