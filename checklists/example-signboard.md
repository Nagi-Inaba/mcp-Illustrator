# 入稿チェックリスト：屋外看板（アルミ複合板）

作成日：2025-01-15
更新日：2025-01-15
印刷会社：看板プリント工房（仮称）
用途：屋外看板（アルミ複合板にインクジェット出力＋ラミネート）

---

## ドキュメント設定

- [ ] カラーモード：CMYK
- [ ] 仕上がりサイズ：900mm × 1800mm
- [ ] 塗り足し：5mm（上下左右均等）※看板は5mm必須
- [ ] 単位：mm
- [ ] ラスタライズ効果解像度：200dpi（大判出力のため）

## テキスト

- [ ] フォント：すべてアウトライン化済み
- [ ] 不足フォントなし
- [ ] 誤字脱字の最終確認（店舗名・電話番号・営業時間を重点チェック）
- [ ] 文字切れ確認：仕上がり線から10mm以上内側にテキストがあるか
- [ ] 最小フォントサイズ：屋外看板は遠距離視認を考慮し24pt以上推奨

## 画像

- [ ] すべての画像が埋め込み済み
- [ ] 画像解像度：150dpi以上（原寸配置時）※大判出力は150〜200dpiで可
- [ ] 画像カラーモード：すべてCMYK

## カラー

- [ ] ドキュメント全体がCMYK
- [ ] 特色：なし（インクジェット出力のためプロセスカラーのみ）
- [ ] オーバープリント設定の確認
- [ ] 白色部分：板の色が出る場合の処理を確認（白インク指定が必要か）
- [ ] 屋外耐候性を考慮：蛍光色は退色しやすいため避ける

## レイヤー・オブジェクト

- [ ] 不要なレイヤーの削除
- [ ] 非表示レイヤーなし
- [ ] 孤立点の削除
- [ ] 不要なスウォッチの削除
- [ ] 切り抜き用のカットパス（必要な場合のみ）

## 特殊仕様

- [ ] ラミネート加工：マットラミネート（屋外耐候用）
- [ ] 取り付け用の穴位置：指示図を別レイヤーまたは別ファイルで用意
- [ ] 角の処理：角丸R指定がある場合は寸法を明記

## 納品形式

- [ ] 保存形式：AI（Illustrator CC互換）
- [ ] PDF互換ファイルを作成：ON
- [ ] 確認用PDF：別途書き出し（入稿データと一緒に送付）
- [ ] ファイル名：案件名_サイズ_日付（例：kanban_900x1800_20250115）

## 看板固有の注意事項

- [ ] 原寸制作か確認（大きすぎる場合は1/2〜1/10縮小制作の場合あり→看板業者に要確認）
- [ ] 縮小制作の場合：縮小率をファイル内に明記
- [ ] ビス穴・金具の位置がデザインにかからないか確認
- [ ] 屋外設置の場合：直射日光・雨風による劣化を考慮した色選び
- [ ] 夜間照明がある場合：照明下での色味を考慮

## 施工情報（看板業者への伝達事項）

- [ ] 設置場所の住所・写真
- [ ] 看板のサイズと設置高さ
- [ ] 設置方法（壁面取り付け / ポール設置 / 自立式 等）
- [ ] 既存看板の撤去が必要か
- [ ] 電飾・照明の有無

## 備考

- 看板は印刷物と異なり、視認距離が遠いため細かいディテールよりも視認性を優先
- インクジェット出力は印刷物よりも色再現の幅が狭い場合がある
- 屋外設置の場合、3〜5年で色褪せが生じるため、メンテナンス計画も提案するとよい
- 施工業者との事前打ち合わせで取り付け方法を確認してからデータ制作に入ること

※ 看板業者によって入稿ルールが大きく異なります。必ず業者の入稿ガイドを確認してください。
※ 縮小率で制作する場合は、解像度の換算に注意してください（例：1/2制作なら300dpi → 原寸150dpi相当）。
