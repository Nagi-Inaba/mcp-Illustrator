# 入稿チェックリスト：イベントポスター A1

作成日：2025-01-15
更新日：2025-01-15
印刷会社：ラクスル
用途：ポスター（屋内掲示）

---

## ドキュメント設定

- [ ] カラーモード：CMYK
- [ ] 仕上がりサイズ：594mm × 841mm（A1）
- [ ] 塗り足し：3mm（上下左右均等）
- [ ] 単位：mm
- [ ] ラスタライズ効果解像度：350dpi

## テキスト

- [ ] フォント：すべてアウトライン化済み
- [ ] 不足フォントなし
- [ ] 誤字脱字の最終確認（日時・会場名・電話番号を重点チェック）
- [ ] 文字切れ確認：仕上がり線から5mm以上内側にテキストがあるか

## 画像

- [ ] すべての画像が埋め込み済み（リンク画像なし）
- [ ] 画像解像度：350dpi以上（原寸配置時）
- [ ] 画像カラーモード：すべてCMYK

## カラー

- [ ] ドキュメント全体がCMYK
- [ ] 特色：なし（プロセスカラーのみ）
- [ ] オーバープリント設定の確認
- [ ] リッチブラック：C40 M40 Y40 K100（大きな黒ベタ部分）
- [ ] K100のみの墨：本文テキストサイズの文字

## レイヤー・オブジェクト

- [ ] 不要なレイヤーの削除
- [ ] 非表示レイヤーなし
- [ ] 孤立点の削除
- [ ] 不要なスウォッチの削除
- [ ] トンボ（トリムマーク）は不要（ラクスルのテンプレート使用時）

## 特殊仕様

- [ ] なし（通常のオフセット印刷）

## 納品形式

- [ ] 保存形式：AI（Illustrator CC互換）
- [ ] PDF互換ファイルを作成：ON
- [ ] ファイル名：半角英数字とアンダースコアのみ使用
- [ ] 入稿時はZIPで圧縮

## ラクスル固有の注意事項

- [ ] ラクスルのテンプレートを使用している場合、テンプレートのガイドラインを削除しない
- [ ] 塗り足し部分まで背景を伸ばしているか確認
- [ ] 入稿データにはアウトライン済みの完成データのみ含める（作業用データは別保存）
- [ ] ラクスルの入稿ガイド（https://raksul.com/guide/）を最終確認

## 備考

- A1ポスターの場合、遠距離から見ることを考慮して最小フォントサイズは10pt以上を推奨
- 写真を大きく使う場合は解像度に特に注意（拡大配置で解像度が下がる）
- 校正刷りが必要な場合は別途手配
